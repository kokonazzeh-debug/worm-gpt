إعداد Hugging Face

المفتاح السري لا يوضع داخل GitHub Pages. ضعه داخل ملف backend/.env على السيرفر فقط.

  1. سجّل الدخول إلى Hugging Face.
  2. افتح صفحة Access Tokens.
  3. أنشئ Fine-grained token وفعّل صلاحية Make calls to Inference Providers.
  4. انسخ المفتاح الذي يبدأ بـ hf_.
  5. افتح backend/.env واكتب: HF_TOKEN=hf_...
  6. لا ترفع ملف .env إلى GitHub.
فتح صفحة طلب المفتاح في Hugging Face العودة إلى NAZZEH AI
مهم: حساب Hugging Face المجاني لديه رصيد تجريبي شهري صغير لـ Inference Providers، وليس استخدامًا مجانيًا بلا حدود. الرصيد والسياسات قد تتغير.
